📍 주소 기반 정보 지도 표시

엑셀 명단 → 주소 지오코딩 → ⭐ 마커로 표시 사용법 / 엑셀 형식 안내 ▾
① 네이버 클라우드 플랫폼(console.ncloud.com) 가입 → Service > Application Services > Maps > Application 등록. 등록 시 Dynamic Map과 Geocoding 두 상품을 모두 활성화하세요. 발급받은 Client ID(Key ID)를 아래 입력창에 넣습니다.
② 이 HTML 파일을 실행할 주소(도메인)를 콘솔의 애플리케이션 설정에 "Web 서비스 URL"로 등록해야 합니다. 이 파일을 그냥 더블클릭(file://)하면 대부분 등록이 안 되므로, 로컬에서 간단한 웹 서버로 열고(예: VSCode의 Live Server 확장, 또는 python -m http.server 실행 후 http://localhost:포트로 접속) 그 주소를 콘솔에 등록하세요. 사내 웹서버에 올려 쓰셔도 됩니다.
③ 엑셀 형식: 첫 번째 행은 머리글(헤더)이며, "주소"라는 이름의 열이 반드시 있어야 합니다(자동 인식되며, 없으면 직접 선택 가능). 나머지 열(이름, 학번, 전공, 전화번호, 회사명 등)은 자유롭게 몇 개든 추가하면 마커 클릭 시 정보창에 그대로 표시됩니다. 전화번호·학번처럼 앞자리 0이 있는 값은 엑셀에서 텍스트 서식으로 입력해 주세요.
④ 같은 주소가 여러 행이면 마커 하나에 인원이 모두 묶여서 표시되고, 별 아이콘에 인원 수 배지가 붙습니다.
⑤ 목록의 체크박스로 지도에 표시할 대상을 개별/전체 선택할 수 있습니다. 선택 해제된 항목은 지오코딩도 하지 않아 API 호출도 절약됩니다.
⑥ 그룹별 색상: 첫 번째 시트에는 '그룹' 열만 넣고, 별도로 'group'이라는 이름의 시트를 만들어 그룹명과 색상을 매핑(그룹, 색상 두 열, 그룹당 1행)해두면 그 그룹에 속한 별 아이콘 색이 자동으로 적용됩니다. 색상 값은 빨강/파랑/초록 등 한글 색상명이나 #FF0000 같은 헥스코드 모두 가능합니다. 왼쪽 상단 그룹 콤보박스로 그룹별 목록만 걸러볼 수도 있습니다.
⑦ 정보창에서 항목 숨기기: 'invisible'이라는 이름의 시트에 첫 번째 시트의 열 이름(예: 학번, 전화번호)을 적어두면, 별풍선을 클릭했을 때 뜨는 정보창에서 그 열은 표시되지 않습니다. (검색이나 CSV 결과 내보내기에는 계속 포함됩니다.) 이 기능은 xlsx 파일(여러 시트 지원)에서만 동작하며 CSV 업로드 시에는 적용되지 않습니다.
